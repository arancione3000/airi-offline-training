# Continuous native training

The user explicitly authorized indefinite training after a focused review. The service has no global deadline or job-count limit. Each epoch is bounded to4096 logical updates,3600 timed training seconds and12 decision rounds; a failed epoch restores the approved champion, rotates the fixed profile and waits5–60 minutes before renewing. Lifetime steps, tokens, Adam/RNG, donor lessons, permanent TRAIN certificates and the materialized TRAIN registry survive. Repeated final/sealed evaluation is excluded from epoch renewal. Original adoption checks and all stored certificates remain mandatory; no live promotion is enabled.

The GitHub-only supervisor uses durable compare-and-swap dispatch claims and a second exclusive claim at job start, committed checkpoint indices, retry limits for transient failures, and persistent epoch cooldowns. Program/integrity failures halt rather than endlessly replaying unsafe state. Scheduled recovery runs every10 minutes; it invokes no assistant or model API. Disable the service by setting `enabled:false` in `control.json` on branch `airi-continuous-control`; cancelling a running training job halts further dispatch. Frozen training code never follows mutable main.
