# Native autonomous context experiment

A bounded 12-hour trial of actual train-step time, starting from the retained native 35635 checkpoint. No pretrained model, teacher API, assistant automation, or student self-labelled training. Existing native source, Adam moments, RNG and production gates are retained.

The solver generates 2,048 training contexts and 32 fixed validation contexts. Stage 0 exposes 256 examples; stages 1 and 2 expose 1,024 and 2,048. Both languages and all four context skills must reach 50% then 75%, including counterfactual pairs, before expansion. Heldout values and prefix are excluded from training. Existing natural conversation probe stays untouched.

Selection reward weights: 45% language/task-balanced context accuracy, 25% both-correct counterfactual pairs, 20% old skills, 10% curated dialogue; repeated-output fraction costs 25%. Selection rejects old skill, dialogue, context-family or pair regressions, excessive repetition, nonfinite metrics and >2% heldout NLL regression. Equal-score candidates need 1% NLL improvement in both languages. These initial coefficients are explicit engineering choices, not empirically calibrated RLHF. Training uses native masked causal supervision, 0.05 repetition-unlikelihood, EOS weight 1.2, anchor KL and gradient clipping. Wrong answers are supervised against known targets, not rewarded for self-confidence.

After two non-improving assessments restore champion weights and Adam, preserve attempted-work counters and current sampler RNG, and reduce learning rate. Curriculum stage and reward history are saved in verified checkpoints. No live promotion. Stops after 12 hours even if progress is absent. The main-branch controller waits for the existing trial and successful native preflight; it starts this trial once. Hourly checks are ordinary GitHub Actions and never invoke ChatGPT. The watchdog retries at most two verified transient failures. Further open-domain self-expansion is not implemented or claimed.
