# Native dialogue-focused cycle — 2026-10-10

User authorized a new autonomous training cycle. Previous experiment completed 43,200.252 seconds and 65,494 attempted updates. Its terminal candidate had 13/28 old probes, 1/16 dialogue, 4/16 foundation, zero context pairs and 1/64 final transfer; original retention and degeneration gates failed. It is not deployed. Retained champion is release airi-offline-49971-37998439310-1-2, with 15 old and 1 dialogue probe correct.

This cycle restores that exact champion's model, Adam moments and RNG. It creates an explicitly new 12-hour ledger while preserving the seed counters as source counters. It shifts sampling to 37.5% old family-balanced authored, 37.5% curated short dialogue, 12.5% composition, 6.25% context and 6.25% native replay. LR is 1e-5 / 5e-6 / 2e-6 and reference KL .25 / .5 / 1, at 4h and 8h of actual compute. These are declared experimental choices, not proven improvements. Existing quality selection and production gates are unchanged.

All previous final-only values remain excluded from training. A different 64-probe final-only set is frozen for this cycle and cannot select the champion. Known native development/test and conversation prompts are excluded. No pretrained weights, external model APIs or student self-labels. Natural conversation remains unverified.

The first bounded chunk is 60 seconds, subsequent chunks up to 3 hours. Full model/optimizer/RNG releases are SHA-verified, index committed last; only successful saves can auto-dispatch another job. Total 12 hours of optimizer compute, at most 32 jobs. Host-independent GitHub execution consumes no hourly ChatGPT calls. Transient retries are bounded by the standalone GitHub watchdog after exact branch/SHA registration. No live promotion.
